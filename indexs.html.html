Tetapan & Sambungan Google Sheet

URL disimpan selamat di pelayar anda.

Cara Memasang Skrip Google Sheet:

  1. Buka Google Sheets baharu di Google Drive.
  2. Klik menu Extensions > Apps Script.
  3. Padam semua kod sedia ada dan tampal kod di bawah:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.clear();
  sheet.appendRow(["Bil", "Tarikh", "No RN", "Nama Pesakit", "Visit Type", "Catatan (Remarks)"]);
  data.forEach(function(row) {
    sheet.appendRow([row.bil, row.date, row.rn, row.name, row.visitType, row.remarks]);
  });
  return ContentService.createTextOutput(JSON.stringify({ "status": "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}
